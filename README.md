# Killer Koalas

The comeback is cuddly. A portrait phone browser game.

**Play: https://ashmerra.github.io/killer-koalas/**

Pull back like a slingshot to fling koalas off the Rock. Cuddle the Moseses before they part your horde. Tap **CUDDLE STAMPEDE** to charge the whole canyon.

Run locally: `scripts/serve.py`, then open http://127.0.0.1:8791/

Check stampede balance: `node scripts/simulate-stampedes.mjs --check`.
See [simulation assumptions and results](docs/stampede-balance.md).
